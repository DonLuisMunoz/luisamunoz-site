Tampa Bay Affordability Analysis

Which Tampa Bay ZIP has gotten least affordable since 2020? Rent vs income for every ZIP, built on Zillow (ZORI, ZHVI) and US Census data. Raw CSVs load into Postgres (running in Docker) staging tables, and every clean step is a new SQL view or table, validated before it counts. The SQL pipeline is done, Power BI is next.

The bug that taught me most
JOIN zhvi zh ON zo.zip = zh."RegionID"

My three-way join returned 0 rows with no error. I'd joined a real ZIP (33510) to Zillow's internal RegionID. 0 rows from an inner join with no error means the keys never matched, not a syntax bug.

JOIN zhvi zh ON zo.zip = zh."RegionName"
