Rules that are load-bearing

1. Never write a raw hex outside tokens/. A test fails the build if you do.
2. Components use semantic tokens, never the room colours. --text, not --ink: at night --text is light, and --ink is still navy.
3. Dusk is a fill. At 1.64:1 on --wall it can never be small text.
4. class styles, data-* targets. JavaScript queries [data-stack], never .skills.
5. Motion answers the visitor. Nothing fades in on scroll. Reduced motion is respected everywhere.
